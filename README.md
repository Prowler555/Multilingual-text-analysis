# Multilingual Text Clustering Pipeline

End-to-end, memory-aware NLP pipeline that cleans raw multilingual text,
generates sentence embeddings, reduces them, and clusters them to discover
topics. Built to run on a single workstation (RTX 4050 6 GB VRAM, 24 GB RAM):
every stage streams, batches, or memmaps its data instead of loading it whole.

> **Status:** stage 1 (data acquisition) implemented. Stages 2-6 are
> scaffolded (CLI, config wiring, I/O contracts, manifest.json output) with
> the core compute left as `TODO`/`NotImplementedError` stubs, filled in
> one at a time. The numbers in the *Results* section are filled in by
> `06_evaluate.py` from real run output - no placeholders.

## Layout

| File | Stage | Purpose |
|------|-------|---------|
| `config.py`         | -  | All paths and tunables in one place |
| `pipeline_common.py`| -  | Logging, formatting, shard writer |
| `01_download.py`    | 1  | Stream a size-capped multilingual Wikipedia slice -> `data/raw/*.jsonl` |
| `02_clean_split.py` | 2  | Blank spaCy + sentencizer, multiprocessing, junk filter -> `data/sentences/*.parquet` |
| `03_embed.py`       | 3  | XLM-RoBERTa base, fp16, batched -> `data/embeddings/emb.f16.memmap` |
| `04_reduce.py`      | 4  | IncrementalPCA 768 -> 50 -> `data/reduced/pca50.f32.memmap` |
| `05_cluster.py`     | 5  | UMAP -> HDBSCAN grid, cluster-count/size report per iteration |
| `06_evaluate.py`    | 6  | Silhouette score (fixed sample) + generated results section |

Each script is standalone and reads the previous stage's output from disk, so
you can rerun any stage without redoing the others.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

## Data source

[`wikimedia/wikipedia`](https://huggingface.co/datasets/wikimedia/wikipedia)
(`20231101` snapshot), streamed from the Hugging Face Hub. Chosen because it is
pre-extracted (clean article text, no wiki markup), ungated, genuinely
multilingual (one config per language), and parquet-backed so streaming caps
bandwidth to what we actually consume.

Default slice: 8 languages (`en es fr de ru zh ja ar`), capped at 4 GB of
extracted text, round-robin across languages.

```bash
python 01_download.py --dry-run     # show plan + disk estimate
python 01_download.py               # run with config.py defaults
python 01_download.py --max-gb 1    # smaller/faster slice
```
